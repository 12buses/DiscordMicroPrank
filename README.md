# MicPrank

Консольная шутка для Windows: случайно выключает ваш микрофон в Discord на несколько секунд.

По умолчанию MicPrank не трогает настройки Windows и не требует Discord API. Он просто нажимает за вас горячую клавишу Discord `Ctrl+Shift+M`. Если глобальные горячие клавиши в Discord выключены, есть режим с кратким переключением на окно Discord и системный режим через WASAPI.

> **Это шутка для друзей, а не для важных звонков.** Начинайте с включённого микрофона: горячая клавиша Discord — переключатель. Если вы уже в муте, «прикол» наоборот включит вас.

## Что умеет

- Случайно выключает микрофон на 2–5 секунд (настраивается).
- Делает паузы 45–150 секунд между приколами (настраивается).
- Работает только с Discord в режиме `hotkey`.
- Умеет прикалываться только во время голосового канала (`--only-in-call`).
- Включает микрофон обратно по Ctrl+C и при штатном выходе.
- Показывает диагностику Discord, аудиоустройств и горячей клавиши.
- Не запускается второй копией: две программы не будут дёргать микрофон одновременно.

## Требования

- Windows 10 или 11, x64.
- Установленный Discord (stable, PTB, Canary или Development).
- .NET 9 Runtime для варианта `framework-dependent` **или** готовый self-contained `.exe` из `dist\self-contained`.
- Для режима `hotkey`: включённая глобальная горячая клавиша Discord **или** параметр `--focus-discord`.
- Запускайте MicPrank с теми же правами, что и Discord. Если Discord обычный, не запускайте MicPrank от администратора: Windows может заблокировать синтетический ввод.

## Быстрый старт

1. Соберите проект (см. раздел «Сборка») или возьмите готовый `.exe`.
2. Запустите диагностику:

   ```powershell
   .\MicPrank.exe --diagnose
   ```

3. В Discord откройте **Настройки пользователя → Горячие клавиши (Keybinds)** и включите глобальные горячие клавиши (Global Keybind). Убедитесь, что действие **Toggle Mute** (выключение микрофона) назначено на `Ctrl+Shift+M`.
4. Начните с **включённого** микрофона.
5. Проверьте один прикол без реального выключения:

   ```powershell
   .\MicPrank.exe --once --dry-run --min-delay 5 --max-delay 5
   ```

6. Проверьте реальный прикол:

   ```powershell
   .\MicPrank.exe --once --min-delay 5 --max-delay 5 --duration 2
   ```

7. Запустите бесконечный режим:

   ```powershell
   .\MicPrank.exe
   ```

Если глобальная горячая клавиша Discord недоступна, используйте один из вариантов:

```powershell
.\MicPrank.exe --focus-discord
```

или

```powershell
.\MicPrank.exe --mode system --device "Realtek" --only-in-call
```

## Режимы

### `hotkey` — по умолчанию

MicPrank отправляет сочетание клавиш через `SendInput`. Если Discord зарегистрировал глобальную горячую клавишу, она сработает даже когда окно Discord не в фокусе. Это самый аккуратный режим: он влияет только на Discord.

Если глобальные горячие клавиши в Discord выключены, программа честно предупредит и не будет делать вид, что работает. Тогда есть два пути:

- включить глобальные горячие клавиши в Discord;
- запустить с `--focus-discord`: перед каждым нажатием MicPrank на мгновение переключит фокус на Discord, отправит клавишу и вернёт фокус обратно.

`--focus-discord` может минимизировать полноэкранную игру и выглядит заметно. Это компромисс, а не невидимый режим.

### `system` — через устройство записи Windows

MicPrank выключает само устройство записи Windows через WASAPI/NAudio. Это работает без горячих клавиш Discord, но микрофон замолкает **во всех приложениях**, которые его используют, а не только в Discord.

Порядок выбора устройства:

1. Если указан `--device <часть имени>`, берётся первое подходящее устройство записи.
2. Иначе MicPrank ищет устройство, на котором есть аудиосессия Discord.
3. Если сессии Discord нет, берётся устройство записи по умолчанию для связи.

Поэтому в системном режиме лучше либо запускать с `--only-in-call`, либо явно указывать `--device`. Например:

```powershell
.\MicPrank.exe --mode system --device "Realtek" --only-in-call
```

Некоторые драйверы и виртуальные устройства игнорируют endpoint mute. На Realtek Audio USB выключение устройства записи проверено: захваченный звук становится нулевым.

## Параметры

| Параметр | Описание |
| --- | --- |
| `--mode hotkey` | Отправлять горячую клавишу Discord (по умолчанию). |
| `--mode system` | Выключать устройство записи Windows. |
| `--system` | То же, что `--mode system`. |
| `--hotkey <сочетание>` | Горячая клавиша Discord, по умолчанию `Ctrl+Shift+M`. |
| `--focus-discord` | Кратко переключаться на Discord перед нажатием. Нужно, если глобальные клавиши Discord выключены. |
| `--only-in-call` | Прикалываться только при активном голосовом канале. |
| `--min-delay <сек>` | Минимальная пауза между приколами, по умолчанию 45. |
| `--max-delay <сек>` | Максимальная пауза, по умолчанию 150. |
| `--duration <сек>` | Фиксированная длительность, например 3. |
| `--min-duration <сек>` | Минимальная длительность, по умолчанию 2. |
| `--max-duration <сек>` | Максимальная длительность, по умолчанию 5. |
| `--device <часть имени>` | Устройство записи для режима `system`. |
| `--once` | Один прикол и выход. |
| `--dry-run` | Показать, что было бы, не выключая микрофон. |
| `--test-hotkey` | Проверить горячую клавишу: выключить на 3 секунды и включить обратно. |
| `--test-focus` | Проверить переключение фокуса на Discord без нажатия клавиши. |
| `--diagnose` | Диагностика Discord, устройств и горячей клавиши. |
| `--verbose` | Подробный вывод. |
| `-h`, `--help` | Справка. |
| `--version` | Версия программы. |

Числа можно писать с точкой или запятой: `--duration 2.5` и `--duration 2,5` работают одинаково.

## Примеры

```powershell
# Бесконечный режим с глобальной горячей клавишей Discord
.\MicPrank.exe

# Если глобальные клавиши Discord выключены
.\MicPrank.exe --focus-discord

# Только во время голосового канала
.\MicPrank.exe --focus-discord --only-in-call

# Системный режим с конкретным микрофоном
.\MicPrank.exe --mode system --device "Realtek" --only-in-call

# Один прикол через 10 секунд, микрофон выключен 3 секунды
.\MicPrank.exe --once --min-delay 10 --max-delay 10 --duration 3

# Проверка без реального выключения
.\MicPrank.exe --once --dry-run --min-delay 5 --max-delay 5

# Проверка горячей клавиши (реально выключит микрофон на 3 секунды)
.\MicPrank.exe --test-hotkey

# Проверка переключения окна Discord
.\MicPrank.exe --test-focus

# Диагностика
.\MicPrank.exe --diagnose
```

## Как это работает

- **hotkey**: `SendInput` отправляет `Ctrl+Shift+M`; Discord обрабатывает свою горячую клавишу. Через случайную паузу MicPrank отправляет её ещё раз, чтобы включить микрофон обратно.
- **system**: MicPrank открывает устройство записи через WASAPI, ставит `AudioEndpointVolume.Mute = true`, ждёт и возвращает `false`.
- **`--only-in-call`**: эвристика по аудиосессиям Discord. Живая сессия на устройстве записи или активная сессия на устройстве воспроизведения считается признаком голосового канала. Если вы одновременно в муте и в режиме «не слышу никого», сессий может не быть, и проверка не сработает.
- **Ctrl+C**: первый Ctrl+C аккуратно завершает прикол и включает микрофон. Второй Ctrl+C завершает процесс принудительно.
- **Один экземпляр**: именованный mutex не даёт запустить две копии.

## Ограничения и предостережения

- **MicPrank не знает состояние мута Discord.** Горячая клавиша — переключатель. Начинайте с включённого микрофона и не трогайте его вручную во время прикола.
- Если Discord уже был в муте, прикол наоборот включит вас на несколько секунд.
- В режиме `hotkey` без `--focus-discord` нужна работающая глобальная горячая клавиша Discord. Проверить это можно через `--diagnose`.
- `--focus-discord` переключает активное окно. Это может свернуть игру, сбить фокус в редакторе или показать Discord поверх другого окна.
- В режиме `system` микрофон выключается для всех приложений. Если процесс убить через Task Manager во время прикола, устройство может остаться выключенным — включите его вручную в настройках звука Windows.
- Некоторые устройства и драйверы не поддерживают endpoint mute или ведут себя странно. Проверяйте `--device` и `--diagnose`.
- Discord может изменить сочетание клавиш или поведение настроек после обновления. Сверьтесь с настройками Discord.
- Не используйте программу в рабочих, учебных или важных звонках. Это шутка.

## Диагностика

```powershell
.\MicPrank.exe --diagnose
```

Вывод показывает:

- запущен ли Discord и сколько у него процессов;
- найдено ли главное окно;
- есть ли, по мнению MicPrank, голосовая сессия;
- свободна ли горячая клавиша (если свободна — Discord не зарегистрировал её глобально);
- все устройства записи, их Windows mute, громкость и аудиосессии;
- устройства воспроизведения с сессиями Discord;
- какое устройство выберет режим `system`.

Типичные сообщения:

- **«Глобальная горячая клавиша ... не зарегистрирована»** — включите глобальные горячие клавиши в Discord или запустите с `--focus-discord`.
- **«Устройство ... уже был выключен в Windows»** — прикол пропущен, чтобы не включить микрофон обратно. Включите устройство вручную.
- **«Discord не запущен»** — запустите Discord; MicPrank будет ждать.
- **«Не удалось отправить горячую клавишу»** — проверьте права (не запускайте от администратора, если Discord обычный) и активное окно.

## Сборка

Нужен .NET 9 SDK.

```powershell
dotnet build -c Release
```

Или одной командой собрать два варианта в `dist`:

```powershell
.\build.ps1
```

Если PowerShell блокирует выполнение скрипта:

```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1
```

Скрипт создаёт:

- `dist\framework-dependent\MicPrank.exe` — небольшой файл, нужен .NET 9 Runtime;
- `dist\self-contained\MicPrank.exe` — всё включено, .NET Runtime не нужен.

Ручная публикация:

```powershell
dotnet publish -c Release -r win-x64 --self-contained false -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -o dist\framework-dependent
dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -p:EnableCompressionInSingleFile=true -o dist\self-contained
```
